# 通用工作区 (General)

## 目的

这是一个**未指定专业领域**的工作区。它只声明"按通用专业标准工作"，不对具体行业、程序或立场作任何假设。

## 本 Profile 提供什么

- 一般性的专业工作标准：先确认事实、区分事实与推断、保留可核验来源。
- 一般性的交付要求：结论明确、依据可追溯、不确定的地方说出来而不是掩盖。
- 一般性的边界意识：在没有明确授权时，不代替用户作决定。

## 本 Profile 不做什么

- 不注入任何特定法域、程序或行业的规则。
- 不假设任务是诉讼、非诉、重整或合规中的任何一类。
- 不改变工具、审批、沙箱或权限规则。

## 与 AGENTS 的关系

AGENTS.md、项目自身的规则文件、工具权限、审批策略与沙箱策略**优先于本 Profile**。本 Profile 只补充领域背景和稳定的工作要求；当两者冲突时，以 AGENTS 和权限规则为准，并明确指出冲突。

## 与 Skill 的关系

本 Profile 不推荐特定 Skill。可用的 Skill 由当前工作区实际安装和启用的集合决定。

## 当信息不足时

说明缺什么、为什么重要、以及用户可以怎样补齐；不要用一般性表述填补具体事实的空缺。
